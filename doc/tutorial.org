* Encoding and decoding a DNS message

mDNS uses the classic DNS wire format.  We build a message with a question and
an answer, serialize it to bytes, and read it back.  The strongest check is that
re-encoding the decoded message reproduces the *exact* bytes — that exercises
name compression in both directions.

#+begin_src lisp
(format t "~%== 1. Encode and decode a DNS message ==~%")
(let* ((msg (make-dns-message
             :id 1234
             :questions (list (make-question :name "_ipp._tcp.local"
                                             :qtype +type-ptr+))
             :answers (list (make-instance 'a-record
                                           :name "printer.local"
                                           :cache-flush t :ttl 120
                                           :address (parse-ipv4 "192.168.1.5")))))
       (bytes (encode-message msg))
       (back  (decode-message bytes)))
  (format t "  encoded ~D bytes~%" (length bytes))
  (check (= 1234 (dns-message-id back)))
  (check (string= "printer.local" (rr-name (first (dns-message-answers back)))))
  (check (equalp bytes (encode-message back))))
#+end_src

* Describing and expanding a service

DNS-SD advertises a *service instance* as a set of records: a shared =PTR=
(type → instance), a unique =SRV= (instance → host:port), a =TXT= of key/values,
one address record per address, and =NSEC= records that say which types exist so
listeners don't wait on absent ones.

#+begin_src lisp
(format t "~%== 2. Describe and expand a service ==~%")
(defparameter *printer*
  (make-service-info :type "_ipp._tcp.local"
                     :name "Front Desk Printer"
                     :host "frontdesk.local"
                     :port 631
                     :addresses (list (parse-ipv4 "192.168.1.5"))
                     :txt '(("rp" . "ipp/print") ("ty" . "Acme LaserJet"))))

(defparameter *records* (service-info-records *printer*))
(format t "  instance: ~A~%" (service-instance-name *printer*))
(format t "  ~D records~%" (length *records*))

(let ((srv (find-if (lambda (r) (typep r 'srv-record)) *records*)))
  (check (find-if (lambda (r) (typep r 'ptr-record)) *records*))
  (check (typep srv 'srv-record))
  (check (= 631 (srv-port srv)))
  (check (string= "frontdesk.local" (srv-target srv))))
#+end_src

* The record cache

Discovered records live in a TTL cache.  It honours the mDNS cache-flush bit and
treats a TTL of zero as a "goodbye" that removes the record.

#+begin_src lisp
(format t "~%== 3. The record cache ==~%")
(let ((cache (make-cache))
      (instance (service-instance-name *printer*)))
  (dolist (r *records*) (cache-add cache r))
  (check (= 631 (srv-port (first (cache-get cache instance +type-srv+)))))
  ;; A goodbye (ttl 0) for the SRV removes it.
  (let ((srv (find-if (lambda (r) (typep r 'srv-record)) *records*)))
    (setf (rr-ttl srv) 0)
    (cache-add cache srv)
    (setf (rr-ttl srv) 120))          ; restore for later sections
  (check (null (cache-get cache instance +type-srv+))))
#+end_src

* Reassembling a service on the discovery side

A browser sees the same records arrive and rebuilds a =service-info= from them —
the inverse of section 2.  Round-tripping our own advertisement proves the two
halves agree.

#+begin_src lisp
(format t "~%== 4. Reassemble on the discovery side ==~%")
(let* ((instance (service-instance-name *printer*))
       (rebuilt  (service-info-from-records "_ipp._tcp.local" instance *records*)))
  (check (string= "Front Desk Printer" (service-info-name rebuilt)))
  (check (= 631 (service-info-port rebuilt)))
  (check (string= "frontdesk.local" (service-info-host rebuilt)))
  (check (equalp (parse-ipv4 "192.168.1.5")
                 (first (service-info-addresses rebuilt))))
  (check (equal '("rp" . "ipp/print")
                (assoc "rp" (service-info-txt rebuilt) :test #'string=))))
#+end_src

* Names are UTF-8, normalized to NFC

Per RFC 6762 §16, names go on the wire as UTF-8 in Unicode Normalization Form C,
so a composed and a decomposed spelling of the same accented name encode to
identical bytes.

#+begin_src lisp
(format t "~%== 5. Names are UTF-8, normalized to NFC ==~%")
(let ((composed   (coerce (list (code-char #xe9)) 'string))        ; é
      (decomposed (coerce (list #\e (code-char #x301)) 'string))   ; e + U+0301
      (wc (make-writer))
      (wd (make-writer)))
  (write-name wc (concatenate 'string "caf" composed ".local"))
  (write-name wd (concatenate 'string "caf" decomposed ".local"))
  (check (equalp (writer-result wc) (writer-result wd))))

(format t "~%All ~D checks passed.~%" *checks*)
#+end_src

* Going live (not run here)

The sections above are all pure — no network — which is why CI can run them.
On a real LAN you'd start a responder and advertise or browse.  This block is
shown for reference only (=:tangle no=), because live multicast needs the network
(and, on macOS 15+, the multicast entitlement on a signed binary).

#+begin_src lisp :tangle no
;; Advertise *printer* on the network:
(let ((responder (0conf:start :services (list *printer*))))
  ;; ... serving ...
  (0conf:stop responder))

;; Live-browse for printers, reacting as they come and go:
(let* ((responder (0conf:start-responder (0conf:make-responder)))
       (browser (0conf:browse-services responder "_ipp._tcp.local"
                  :on-add    (lambda (info) (format t "+ ~A~%"
                                                    (0conf:service-instance-name info)))
                  :on-remove (lambda (name) (format t "- ~A~%" name)))))
  ;; ... discovering ...
  (0conf:stop-browse browser)
  (0conf:stop responder))
#+end_src
